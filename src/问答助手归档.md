# 赛事补给问答助手归档

## 命令行原型

在仓库根目录完成依赖安装后运行以下命令。首次运行需要下载本地嵌入模型。

```powershell
.\.venv\Scripts\python.exe examples/rag_demo.py --device cpu --question "试点如何验收？"
```

示例默认只检索。按[配置说明](../config/README.md)配置模型后可加 `--answer` 生成答案。代码通过 BM25 与 FAISS 结合检索文档片段。演练报告用于说明试点约束，真实批次状态需要有授权的业务记录。

## Web MVP 演示路径

1. 按[启动步骤](../README.md)初始化账号并启动服务。
2. 管理员进入 `/admin/knowledge`，上传 Markdown 或 PDF，等待索引完成后发布。
3. 员工登录聊天页，输入“试点如何验收？”，检查命中片段及来源。未配置对话模型时使用“仅检索”。
4. 如需演示 Agent，由管理员准备已发布批次和确认后的规则。员工询问对应批次，查看核对结果及来源。有草稿预览时，按页面提示分两次确认创建与提交。

| 演示问题 | 预期核查点 |
| --- | --- |
| 试点如何验收？ | 可定位访谈中关于 60 条样本、单位转换及人工复核的依据 |
| 这批物资箱数和份数能直接比较吗？ | 有批准规则时展示换算依据，缺规则时提示人工确认 |
| 尚未导入的站点签收了多少？ | 提示资料不足，保留证据缺口 |

表内为可重跑的验收示例。实际在线模型验证记录见[运行验证](../docs/真实模型运行验证.md)。运行时数据库、密钥、模型缓存和员工私有资料均由部署环境管理。
