# 聊天页面适配验证

运行截图：[桌面页面](images/聊天页面_桌面.png) · [手机页面](images/聊天页面_手机.png)。截图使用合成演练资料，不含登录密码或API密钥。

日期：2026-10-30。页面仍为HTML与原生JS，未改变已有角色权限和问答接口。

- 输入区固定在聊天卡片底部，发送按钮紧邻文本框；展开引用或草稿时不被长消息挤出视口。
- 消息和侧栏分别滚动；长引用与工具记录有独立滚动限制。
- 桌面采用侧栏＋聊天双栏，900px以下改为可关闭抽屉，手机隐藏非必要说明。
- 统一字号、行距、留白、消息层次与主按钮样式，优化安全区域和动态视口高度。
- 支持Enter发送、Shift+Enter换行；中文输入法组合期间不触发发送。
- Agent模式明确显示当前模式，并禁用无效的“仅检索”开关，减少歧义。
- 输入临时草稿按当前用户在浏览器会话中隔离保存；发送中展示处理中状态。
