## 问题与现状流程

```text
站点需求 → 库存核对 → 装车 → 签收 → 余料回收
```

流程来源为 f01/f20。主要问题是跨工具缺少统一关联编号（f30）、仓库按箱而站点按份（f50）、版本和未确认项交接不清（f23–f25）。现场希望得到一页缺项清单及来源位置（f15）。

## 建议的首期切口（尚待确认）

先用一个虚构配送批次，制作“只读核对与追溯”原型：读取脱敏样本 → 检查关键字段、关联、单位与版本 → 展示缺项及原行来源 → 留给具名人员复核。REQ-1/REQ-2 是核对前提，REQ-4 是主要展示形式，REQ-3/REQ-5/REQ-6 提供必要边界。此建议不表示已经实现或完成需求选择。

不预设箱/份换算率，不自动向现有工具写回、发消息、执行派单或确认结论（f22/f32/f41）。食品安全、医疗补给与应急调度由业务人员决定（f05/f52）。
