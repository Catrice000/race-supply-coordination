# 真实DeepSeek Agent运行验证

验证日期：2026-10-30（香港时间）。本次通过本机网页实际调用DeepSeek官方API，模型为`deepseek-flash`，不是脚本模型替身。

## 场景与结果

全部输入为合成演练：赛事`EVT-DEMO-1030`、批次`B001`、站点`S01`，饮用水需求24份、出库1箱、签收20份。管理员发布演练文档，并人工确认演练换算口径为每箱24份。

真实模型自主依次调用：

1. `search_knowledge`：检索已发布的演练规则。
2. `get_batch_records`：读取授权批次快照。
3. `validate_batch`：后端依据已确认的换算计算出库24份、签收20份。
4. `create_review_draft`：凭有效校验和本次用户授权创建内部复核草稿。

HTTP返回200，总耗时约7.67秒，四个工具均无错误，成功创建一份未提交草稿。没有自动提交、正式审批或库存写回。数量差异为4份；计算由后端执行，模型负责选择工具。

通过浏览器打开真实运行会话，确认页面可显示易读数量对比、演练标识、文件引用与原文片段。结果保存在本机SQLite会话与工具审计中。运行服务地址为本机`http://127.0.0.1:8000/`，不是公网部署。

## 配置与边界

真实密钥仅写入已被Git忽略的本机`.env.local`，不包含在源码、本文或GitHub提交中。演示账户信息也仅保存在被忽略的本机`work/`中；仓库没有通用默认账户。

此前的回归和浏览器测试使用脚本模型替身；本次补充了真实模型的完整建草稿链路。单次成功不能代表模型在所有问题上的工具选择准确率，也不能代替客户正式资料和验收评测。
